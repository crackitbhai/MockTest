Q61. Which type of malware replicates itself to spread to other computers across a network?

A) Trojan Horse
B) Worm
C) Adware
D) Spyware

Correct Answer: B) Worm

Explanation: Unlike viruses, computer worms are standalone malware that replicate and spread without human intervention.

Q62. What does HTTPS use for encrypting communication over the computer network?

A) SSL / TLS protocol
B) FTP tunneling
C) DNS security keys
D) MAC address masking

Correct Answer: A) SSL / TLS protocol

Explanation: HTTPS secures web traffic using Secure Sockets Layer (SSL) or Transport Layer Security (TLS).

Q63. Which gate is known as a universal logic gate because it can implement any Boolean function?

A) AND / OR
B) NAND / NOR
C) XOR / XNOR
D) NOT only

Correct Answer: B) NAND / NOR

Explanation: NAND and NOR gates can be combined to build any logic gate or circuit.

Q64. What is the base of the Hexadecimal number system?

A) 2
B) 8
C) 10
D) 16

Correct Answer: D) 16

Explanation: Hexadecimal uses 16 symbols ranging from 0-9 and letters A-F.

Q65. Which command in Linux is used to view the contents of a text file?

A) ls
B) cat
C) pwd
D) cd

Correct Answer: B) cat

Explanation: The cat (concatenate) command is commonly used to display file contents in terminal.
