📝 Advanced Practice Questions (PHP & Database) - Page 1

Showing questions 1 to 20 of high-level competitive standards.

Q1. Which of the following PHP superglobal variables is used to collect data sent via both HTTP GET and POST methods?

A) $_GET
B) $_POST
C) $_REQUEST
D) $_SERVER

Correct Answer: C) $_REQUEST

Explanation: $_REQUEST is a PHP super global variable which contains submitted data via GET, POST, and COOKIE mechanisms.

Q2. Which normal form deals specifically with removing Transitive Functional Dependencies in a relational database?

A) First Normal Form (1NF)
B) Second Normal Form (2NF)
C) Third Normal Form (3NF)
D) Boyce-Codd Normal Form (BCNF)

Correct Answer: C) Third Normal Form (3NF)

Explanation: A relation is in 3NF if it is in 2NF and every non-prime attribute is non-transitively dependent on primary key.

Q3. Which function must be called at the very beginning of a PHP script before accessing any session variables?

A) session_start()
B) start_session()
C) init_session()
D) session_begin()

Correct Answer: A) session_start()

Explanation: session_start() creates a session or resumes the current one based on a session identifier passed via a GET or POST request, or passed via a cookie.

Q4. What is the primary performance benefit of creating an Index on a database table column?

A) It speeds up data insertion (INSERT operations)
B) It speeds up data retrieval (SELECT queries)
C) It reduces the physical storage size of the table
D) It automatically encrypts the sensitive column data

Correct Answer: B) It speeds up data retrieval (SELECT queries)

Explanation: Indexes allow the database engine to find data without scanning the entire table, drastically improving SELECT query performance.

Q5. In PHP, what does the null coalescing operator (`??`) do?

A) Checks if a variable is strictly equal to boolean false
B) Returns its first operand if it exists and is not null; otherwise returns second operand
C) Compares two expressions and returns 0 if they are identical
D) Converts any object string into a null pointer safely

Correct Answer: B) Returns its first operand if it exists and is not null; otherwise returns second operand

Explanation: The ?? operator is syntactic sugar for checking if a variable exists and is not null before assigning a default value.

Q6. Which SQL JOIN returns all records when there is a match in either the left or the right table records?

A) INNER JOIN
B) LEFT JOIN
C) FULL OUTER JOIN
D) CROSS JOIN

Correct Answer: C) FULL OUTER JOIN

Explanation: FULL OUTER JOIN combines the results of both left and right outer joins, returning all records from both tables.

Q7. Why is PHP Data Objects (PDO) preferred over the legacy `mysql_*` functions for database connection?

A) PDO supports prepared statements which prevent SQL injection
B) PDO is database-agnostic supporting multiple database systems
C) Legacy mysql functions are deprecated and removed in modern PHP versions
D) All of the above

Correct Answer: D) All of the above

Explanation: PDO provides an abstraction layer, security via prepared statements, and is standard modern practice as old mysql extensions were dropped in PHP 7.

Q8. Which of the following acronyms represents the four key properties of a reliable database transaction?

A) SPEED
B) ACID
C) BASE
D) SAFE

Correct Answer: B) ACID

Explanation: ACID stands for Atomicity, Consistency, Isolation, and Durability, ensuring safe transaction processing in DBMS.

Q9. Which function starts output buffering in PHP, allowing header() modifications later in the script?

A) ob_start()
B) buffer_init()
C) start_buffer()
D) php_buffer_on()

Correct Answer: A) ob_start()

Explanation: ob_start() turns on output buffering. While output buffering is active, no output is sent from the script; instead the output is stored in an internal buffer.

Q10. Which SQL constraint ensures that all values in a column are different and does not allow any NULL values?

A) UNIQUE
B) CHECK
C) PRIMARY KEY
D) FOREIGN KEY

Correct Answer: C) PRIMARY KEY

Explanation: A primary key uniquely identifies each record in a table and inherently enforces both UNIQUE and NOT NULL constraints.

Q11. What is the purpose of scalar type declarations like `declare(strict_types=1);` in PHP?

A) It converts all strings to uppercase automatically
B) It forces strict data type matching for function arguments and return types
C) It disables all database error warnings in production
D) It increases execution speed by caching PHP opcodes

Correct Answer: B) It forces strict data type matching for function arguments and return types

Explanation: strict_types=1 ensures that if a function expects an integer, passing a string representation of a number throws a TypeError instead of coercing it.

Q12. What is a Database View?

A) A physical backup table stored on hard disk
B) A virtual table based on the result-set of an SQL statement
C) A graphical user interface tool to manage servers
D) An index structure used for fast searching

Correct Answer: B) A virtual table based on the result-set of an SQL statement

Explanation: A view contains rows and columns, just like a real table, but its fields are fields from one or more real tables in the database.

Q13. Where are PHP Session data variables securely stored by default?

A) Directly inside the user's browser local storage
B) On the server side in temporary files or database
C) Inside the client cookies encrypted via MD5
D) In the web server RAM cache only

Correct Answer: B) On the server side in temporary files or database

Explanation: Unlike cookies which reside on the client's machine, PHP sessions store sensitive user data securely on the server side.

Q14. Which SQL clause is used in conjunction with aggregate functions to filter groups of rows?

A) WHERE
B) HAVING
C) FILTER
D) GROUP BY condition

Correct Answer: B) HAVING

Explanation: The HAVING clause was added to SQL because the WHERE keyword could not be used with aggregate functions.

Q15. In PHP Object-Oriented Programming, what is the correct syntax for declaring a constructor method?

A) function construct()
B) public function __construct()
C) _init_class()
D) class_initialize()

Correct Answer: B) public function __construct()

Explanation: PHP uses double underscores (__construct) for constructor magic methods in classes.

Q16. What causes a Database Deadlock situation?

A) When two or more transactions are waiting for each other to release locks
B) When the CPU usage exceeds 100% capacity
C) When a primary key constraint fails during insertion
D) When the PHP execution timeout limit is reached

Correct Answer: A) When two or more transactions are waiting for each other to release locks

Explanation: A deadlock occurs when separate transactions hold locks on resources the other needs, causing a permanent freeze until the DBMS aborts one.

Q17. Which built-in PHP function is recommended for securely hashing user passwords?

A) md5()
B) sha1()
C) password_hash()
D) crypt_secure()

Correct Answer: C) password_hash()

Explanation: password_hash() creates a secure password hash using strong, modern, and salted cryptographic algorithms like Bcrypt or Argon2.

Q18. What is the main purpose of a Foreign Key constraint in a relational database?

A) To ensure referential integrity between two tables
B) To speed up multi-table query joins automatically
C) To encrypt foreign language characters in text columns
D) To allow duplicate primary keys across databases

Correct Answer: A) To ensure referential integrity between two tables

Explanation: A foreign key links child table data to the primary key of a parent table, preventing orphan records.

Q19. What is the fundamental difference between `include` and `require` in PHP when a file is missing?

A) require throws a fatal error and stops script execution; include only throws a warning and continues
B) include throws a fatal error; require throws a warning
C) require works only with databases; include works with files
D) There is no difference between them

Correct Answer: A) require throws a fatal error and stops script execution; include only throws a warning and continues

Explanation: Use require when the file is critical for application execution, and include when the file is optional.

Q20. Which SQL clause is mandatory when you want to apply aggregate functions across different categories in a table?

A) ORDER BY
B) GROUP BY
C) SORT BY
D) CLUSTER BY

Correct Answer: B) GROUP BY

Explanation: GROUP BY groups rows that have the same values into summary rows, enabling aggregate functions like COUNT, SUM, or AVG.
