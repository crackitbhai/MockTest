Showing questions 21 to 40 of high-level competitive standards.

Q21. Which PHP function is used to get the length of a string?

A) stringlength()
B) strlen()
C) length()
D) str_size()

Correct Answer: B) strlen()

Explanation: The strlen() function returns the length of a string in bytes.

Q22. What does SQL stand for?

A) Structured Query Language
B) Simple Question Language
C) Standardized Query Logic
D) Server Query Linux

Correct Answer: A) Structured Query Language

Explanation: SQL is a standard language for managing and querying data in relational database management systems.

Q23. Which symbol is used to start a variable name in PHP?

A) #
B) @
C) $
D) &

Correct Answer: C) $

Explanation: All variables in PHP start with a dollar sign ($) followed by the name of the variable.

Q24. Which SQL command is used to remove a table from a database?

A) DELETE TABLE
B) DROP TABLE
C) REMOVE TABLE
D) CLEAR TABLE

Correct Answer: B) DROP TABLE

Explanation: The DROP TABLE statement deletes a table completely along with its structure and data.

Q25. Which function in PHP is used to output text to the browser?

A) print() / echo
B) display()
C) write()
D) scan()

Correct Answer: A) print() / echo

Explanation: echo and print are constructs used to output data in PHP.
