Showing questions 41 to 60 of high-level competitive standards.

Q41. Which OSI layer is responsible for process-to-process delivery of an entire message?

A) Transport Layer
B) Network Layer
C) Data Link Layer
D) Session Layer

Correct Answer: A) Transport Layer

Explanation: The transport layer ensures complete data transfer from source to destination process.

Q42. What is the default port number for HTTP protocol?

A) 21
B) 25
C) 80
D) 443

Correct Answer: C) 80

Explanation: Port 80 is the standard port for unencrypted HTTP web traffic.

Q43. Which scheduling algorithm allocates CPU to the process with the shortest next CPU burst?

A) FCFS
B) SJF (Shortest Job First)
C) Round Robin
D) Priority Scheduling

Correct Answer: B) SJF (Shortest Job First)

Explanation: SJF minimizes average waiting time for a given set of processes.

Q44. What does IP address version 4 (IPv4) consist of in terms of bit length?

A) 32 bits
B) 64 bits
C) 128 bits
D) 16 bits

Correct Answer: A) 32 bits

Explanation: IPv4 addresses are 32-bit integers divided into 4 octets.

Q45. Which of the following is a deadlock prevention method?

A) Mutual exclusion holding
B) Banker's Algorithm
C) Circular wait elimination
D) Process termination loop

Correct Answer: C) Circular wait elimination

Explanation: Eliminating any of the 4 Coffman conditions (including circular wait) prevents deadlock.
